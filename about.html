About AirmidWiki

AirmidWiki is a documentation website intended to make published software release information and approved system documentation easier to find and understand.

What can I do here?

  • Release History: Find a release by version and date.
  • Release Details: Read recorded changes, item statuses, and related screenshots where available.
  • Configuration: Read approved system configuration documentation.

How is it updated?

This is a static HTML site. An authorized person updates the HTML files and adds approved screenshot files before publishing.

Screenshot and data safety

Use approved test data or redact sensitive information before adding screenshots. Do not include patient-identifying information, passwords, API keys, or other secrets.
