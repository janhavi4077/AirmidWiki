How to use AirmidWiki

  1. Open Release History .
  2. Choose the release version you need.
  3. Read the summary table first, then open the relevant module or item.
  4. Use screenshots to identify the screen or change being documented.

This is a static HTML documentation site. It must be opened from the project folder or published through an approved company location to be shared as a team URL.
