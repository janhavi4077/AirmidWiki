AirmidWiki_New — Structured HTML project

OPEN THE SITE
1. Extract this ZIP file to a folder.
2. Open index.html in a browser to view the homepage.
3. Use the navigation at the top to move between pages.

FILES
- index.html: Home page and navigation guide
- releases.html: Release overview and status key
- release-r2.5.html: R2.5 details, grouped by module, with included screenshots
- release-r2.6.html: R2.6 overview, item summary, and detailed item sections
- release-details.html: Reusable template for future release documentation
- configuration.html: Configuration documentation placeholder
- about.html: Purpose, usage, and screenshot safety notes
- screenshots/: Images used by the R2.5 page

PROJECT RULES
- Plain HTML with inline style attributes only.
- No external CSS, JavaScript, database, or API.
- Image paths are relative to this folder, so keep the screenshots folder beside the HTML files.
- R2.6 screenshot areas remain placeholders because screenshots for those items were not included in the uploaded ZIP.
- R2.5 item 2349 is marked Completed overall, but one description point is marked “discuss”; confirm this before publishing as final.
- Verify dates and release labels against the approved release note.
- Use approved test data; do not include patient-identifying information, passwords, API keys, or other secrets.

SHARING
This ZIP is a local static HTML site. It is not published online. For a team-wide URL, use a company-approved hosting or internal document platform.


RECOMMENDED CONTENT STRUCTURE
1. Start each release page with the release overview and summary table.
2. Group detailed items by module and keep each item ID visible.
3. Preserve statuses and descriptions from the approved source.
4. Add user instructions only when the actual workflow is confirmed.
5. Use screenshots only when approved for documentation; test screenshots are placeholders, not final evidence.
6. Keep any unresolved status or wording discrepancy visible for confirmation rather than guessing.
